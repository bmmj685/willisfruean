# Willis Fruean — Professional Portfolio

A deploy-ready, responsive static portfolio built from Willis Fruean's current CV.

## Files
- `index.html` — complete website
- `style.css` — responsive design
- `script.js` — mobile navigation + subtle reveal animations
- `assets/willis-fruean.png` — portrait
- `README.md` — deployment notes

## Deploy immediately

### Netlify
1. Unzip the project.
2. Open Netlify and choose **Add new site → Deploy manually**.
3. Drag the `willis-fruean-portfolio` folder into the upload area.

### Vercel
1. Upload this folder to GitHub.
2. Import the repository into Vercel.
3. Select a static/Other framework preset.
4. Deploy.

### GitHub Pages
Upload the project to a GitHub repository, then enable Pages for the main branch and root folder.

No npm install or build command is required.
