# Personal Portfolio — Samoa

A responsive, single-page personal portfolio for a Distribution Area Manager, singer and guitarist.

## Quick deploy

### Netlify
1. Unzip this folder.
2. Go to Netlify and choose **Add new site → Deploy manually**.
3. Drag the `brother-portfolio` folder into the upload area.

### Vercel
1. Put this folder in a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: **Other** / static site.
4. Deploy.

### GitHub Pages
1. Upload the project to a GitHub repository.
2. Go to Settings → Pages.
3. Select the main branch and `/root`.
4. Save.

## Before publishing
- Replace `hello@example.com` in `index.html` with his real email.
- Replace the `A` in the logo with his first initial if needed.
- Add more photos to `assets/` and extend the gallery if desired.
- Replace the demo music player with a real audio file or streaming link if he wants visitors to hear his songs.

No build step or npm install is required. Open `index.html` directly to preview it.
